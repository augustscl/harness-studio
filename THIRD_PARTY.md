# Third-party software

Harness Studio bundles `@deepseek-ai/dsh@0.1.0-rc.6` and its production dependency closure so the application can run without a global Node.js or Harness installation.

- DeepSeek Harness repository: <https://github.com/deepseek-ai/deepseek-harness>
- DeepSeek Harness package: <https://www.npmjs.com/package/@deepseek-ai/dsh>
- DeepSeek Harness top-level license: MIT

The packaged dependency tree contains software under additional open-source and custom licenses. The authoritative license files and notices shipped by those packages remain inside the application bundle under `Contents/Resources/app/node_modules`.
